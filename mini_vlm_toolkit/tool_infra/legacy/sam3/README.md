# Legacy SAM3 Tools

This folder stores deprecated SAM3 tooling and tests kept for historical reference.

These files are intentionally outside `src/tools/` so `LIGHT_TOOL_MODULES=auto`
will not discover or load them.

Supported SAM3 runtime path is now:
- `src/tools/sam3_segment_new/tool.py` (`Visual_Grounding_Tool`)
